# 증거 자료 보관 원칙

이 폴더에는 **민감정보를 제거한** 구현 화면, 시험 입력/출력, 개선 전후 비교 캡처를 기록합니다.

- 예: `F-01_forms_submission_redacted.png`, `AI-02_missing_source_result.png`
- 각 캡처에 테스트 ID·일시·사용한 가상 데이터·결과를 `tests/test_runs.csv`와 함께 기록합니다.
- 실제 교육생 개인정보, 담당자 계정, 이메일 주소, 내부 공지 원본은 올리지 않습니다.
- 아직 검토되지 않은 사용자의 기존 스크린샷은 자동으로 첨부하지 않았습니다.
