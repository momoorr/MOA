# 최종 발표 PPT 구성안 (8~10장, 초안)

1. **프로젝트 소개:** AI 교육운영 문의 관리 서비스, 한 줄 설명
2. **문제 발견:** 직접 관찰한 반복 문의·정보 출처 분산 / 검증 한계
3. **문제 정의·대상 사용자:** 교육생과 운영 담당자의 업무 흐름
4. **대안 비교·차별화:** 기존 공지/FAQ/담당자 문의 방식과 비교
5. **핵심 요구사항·사용자 흐름:** 문의 접수 → AI 분류 → 검토 → 처리
6. **구성도·AI 역할:** Forms, Sheets, 자동화, 모델, 사람이 하는 일
7. **시연:** 가상 문의 입력부터 분류·확인까지 (실제 구현 범위에 맞춰 수정)
8. **검증 결과:** 시험 ID별 기대/실제·오류·재시험과 개선 전후
9. **운영·사업화:** 비용, 권한, 유지관리, 도입 시 고려사항
10. **한계·회고·향후 계획:** 직접 수행 범위, 미구현 기능, 배운 점

### 시연 원칙
- 실제 구현된 기능만 라이브 시연 또는 녹화로 보여준다.
- 실패에 대비해 민감정보를 제거한 영상/캡처를 준비한다.
- 가상 데이터와 실제 사용자 검증 결과는 발표에서도 분리한다.

### 필요한 캡처 목록
- [ ] 문의 접수 양식
- [ ] 제출 후 응답 저장 결과
- [ ] AI 분류 결과(초안/근거 포함)
- [ ] 담당자 검토/처리 상태 변경
- [ ] 오답 또는 정보 부족 사례와 처리 결과
- [ ] 시험 결과표 / 개선 전후 자료
