# 운영 및 인계 안내 (초안)

## 현재 확인한 구성
- 문의 접수: Google Forms
- 응답 보관: Google Sheets 파일 `AI_교육운영_문의관리_MVP`의 응답 시트
- 시험용 관리 데이터: 같은 파일의 별도 시트
- AI 자동화: 아직 미구현

## 수동 확인 절차
1. Google Forms의 '응답' 탭을 열어 응답 수를 확인한다.
2. 연결된 Google Sheets 응답 시트를 열어 A열(타임스탬프), B열(문의 내용)을 확인한다.
3. 접수된 내용에 실제 개인정보가 있으면 공개 자료로 복제하지 않는다.

## 미구현·미검증 사항
- 자동 문의 ID 발급
- AI 분석 실패 시 재시도
- 데이터 백업/복원 절차
- 담당자별 권한 통제
- 상태 변경 감사 이력

이 문서는 MVP 구현과 시험에 따라 실제 재현 가능한 절차로 보완한다.
