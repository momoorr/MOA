# 문제 정의 및 검증 근거 (초안)

## 목표 사용자
- 1차: 기업교육 운영 담당자 / 강사
- 2차: 교육생

## 관찰한 사례 (실제 교육생 관점)
- 교육생이 프로젝트 기간이나 교육 일정, 출결 관련 질문을 하는 모습을 관찰함.
- 프로젝트 주제, 프로젝트 구성 방법, 이전 프로젝트와 최종 프로젝트의 진행 방식 차이에 관한 질문이 있었음.
- 개별 상담에 관한 안내가 있었음.
- 운영 담당자는 일정 문의 시 일정표나 공지를 확인한 뒤 답변하는 사례가 있었음.
- 공식 일정은 홈페이지/플랫폼, 학원 전체 일정은 단체 채팅방이나 담당자, 강사의 세부 일정은 구두로 확인할 수 있는 환경임.
- 선생님이 수업 중 일정을 꾸준히 안내해, 본인은 일정 정보를 별도로 찾지 않은 사례도 있음.
- 비슷한 일정 질문이 반복되는 모습을 관찰함.

## 확인되지 않은 사항
- 운영 담당자의 문의 처리 소요 시간과 반복 업무 부담
- 교육생 다수가 정보를 찾기 어려워하는지 여부
- AI를 도입했을 때 실제 절감 시간 / 비용
- 교육기관의 도입 의사 또는 구매 의향

## 현재 문제 가설
반복되는 문의를 공식 자료에 근거해 분류하고, 답변 가능한 문의와 사람의 확인이 필요한 문의를 구분하면 교육 운영 업무를 지원할 수 있다.

## 검증 방법
- 가상 문의로 처리 규칙 및 AI 출력 검증
- 가능하면 교육생 1~2명의 추가 피드백 확보 (실제 진행 시 기록)
- 동일 조건에서 기존 방식 vs AI 보조 방식의 소요 시간 비교
- 실제 운영자 검증이 어렵다면 **사용자 검증의 한계**를 최종 보고서에 명시
