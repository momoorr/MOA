# 경쟁 서비스 및 사업화 검토 (작성 예정)

## 목표 고객 가설
기업교육 운영팀, 교육기관 운영 담당자, 사내 교육 담당자

## 경쟁 및 대체 방식
- 기존 대체 방식: 공지사항·단체채팅·담당자 직접 답변
- 조사할 경쟁 유형: LMS, 헬프데스크/티켓 관리, 생성형 AI 챗봇

## 조사할 항목
| 솔루션/대체 방식 | 확인한 날짜 | 주요 기능 | 요금/도입 조건 | 강점·한계 | 근거 URL |
|---|---|---|---|---|---|
| 추후 입력 |  |  |  |  |  |

## 차별화 가설
공식 근거가 명확한 질문만 답변 초안을 만들고, 근거가 없으면 정보 확인 또는 상담 요청으로 전달하는 운영 지원 흐름.

## 사업화 시 검토할 내용
- 고객이 실제로 지불할 필요를 느끼는 문제인지
- AI 모델 호출 비용 및 수동 검토 비용
- 공지 문서 최신 상태 유지 책임
- 개인정보 처리·권한·보관 기간
- 도입·운영 비용과 지원 범위

※ 시장 규모, 매출, 고객 의향은 조사·확인 전까지 기입하지 않는다.
