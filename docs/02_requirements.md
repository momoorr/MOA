# MVP 요구사항 v0.1

| ID | 요구사항 | 우선순위 | 현재 상태 | 검증 방법 |
|---|---|---|---|---|
| REQ-01 | 교육생이 문의 텍스트를 입력할 수 있다 | 필수 | Google Forms 양식 설정 완료 | 가상 문의 제출 |
| REQ-02 | 입력한 문의가 관리 시트에 저장된다 | 필수 | Forms–Sheets 연결 설정 확인 / 제출 검증 예정 | 응답 시트 값·시각 확인 |
| REQ-03 | AI가 문의를 공통 안내/정보 확인 필요/개별 상담으로 분류한다 | 필수 | 수동 테스트 3건 통과 / 자동화 미구현 | 가상 문의 반복 시험 |
| REQ-04 | 공식 근거가 있을 때만 답변 초안을 작성한다 | 필수 | 규칙 설계·수동 테스트 | 문서 있는 문의와 없는 문의 비교 |
| REQ-05 | 개인정보/출결/개별 상담을 담당자 확인 대상으로 표시한다 | 필수 | 규칙 설계 | 권한 확인·상담 문의 시험 |
| REQ-06 | 운영 담당자가 결과를 수정하고 상태를 변경할 수 있다 | 필수 | 시트 열 설계 / 실제 업무 흐름 시험 전 | 수동 변경·저장 검증 |
| REQ-07 | 처리 이력 및 시험 결과를 기록한다 | 필수 | 템플릿 준비 | 시험 ID와 결과 추적 |
| REQ-08 | AI 에이전트가 필요한 도구를 실제 선택·호출한다 | 확장 | 미구현 | 도구 호출 추적 기록 |
| REQ-09 | 공지/운영 문서 검색 및 출처 표시 | 확장 | 미구현 | 근거 링크·본문 일치 검사 |

원칙: 필수 기능을 먼저 완성한다. 미구현 기능은 구현 완료로 기록하지 않는다.
