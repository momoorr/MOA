# MOA 테스트 기록: 미처리 문의 복구와 AI 답변 근거 검증

> 2026-10-30 / 가상 데이터 기능시험 / SKT ALEPH 개인 캡스톤

## 1. 기록 목적

기본 자동화가 작동하더라도 누락된 문의와 근거 없는 AI 안내를 별도로 발견·처리할 수 있는지 검증했다. 테스트 화면은 사용자가 직접 확인한 결과를 기준으로 기록했으며, 운영 환경의 성능을 뜻하지 않는다.

## 2. 재처리 흐름 검증 — MOA-3

- **사전 상태:** 관리 시트 `시트1`의 6행, 문의ID `MOA-3`, 상태 `재처리 대기`.
- **입력 문의:** `교육 플랫폼에서 과제를 제출하려면 어떤 메뉴를 이용해야 하나요?`
- **시나리오:** `MOA - Retry Pending Inquiries` (Make, 수동 실행).
- **구현한 흐름:** Google Sheets Search Rows(`처리 상태 = 재처리 대기`) → Gemini Generate a response → JSON Parse JSON → Google Sheets Update a Row.
- **기대 결과:** 원래의 문의ID 및 문의 내용 보존, 동일 6행에 AI 분류·초안·근거 기록, 상태 `검토 대기`, 신규 중복 행 없음.
- **실제 관찰:** 4개 모듈 모두 실행 성공, `MOA-3` 6행의 분류·답변·근거가 기록되고 상태가 `검토 대기`로 바뀜. 7행은 비어 있어 새 중복 기록은 관찰되지 않음.
- **판정:** **재처리 흐름 기능시험 통과**.
- **제약:** 최초 원본 3행이 자동 처리되지 않았던 정확한 원인은 아직 확정되지 않음. 이 실험은 원인 해결이 아니라 **누락 건을 안전하게 복구하는 기능**을 확인한 것임.

## 3. AI 답변 공식 근거 준수 검증 — 재시험

### 적용 가능한 가상 공식 안내자료

`과제는 교육 플랫폼의 '과제 제출' 메뉴에서 제출한다.`

### 수정 전 (품질 실패)

> 교육 플랫폼에서 과제를 제출하시려면 로그인 후 '학습 관리' 또는 '내 강의실' 메뉴로 이동하신 뒤, 해당 과목의 '과제' 탭을 선택하여 제출해 주시기 바랍니다.

- 분류: `공통 안내` — 기대 분류와 일치.
- 답변 품질: **실패**. 안내자료에 없는 `학습 관리`, `내 강의실`, `과제 탭`, 로그인 이후 이동 절차를 추가함.
- 판단 근거도 구체적인 공식 자료 내용이 아니라 일반적인 분류 이유를 제시함.

### 적용한 개선

재처리 시나리오의 Gemini System Instructions에 **공식 자료에 없는 메뉴명·경로·절차를 추가하지 말 것**, **실제 근거 내용을 명시할 것**, **문의와 무관한 안내를 제외할 것** 등의 규칙을 추가함. JSON 출력 키(category, action, content, reason)는 유지함.

### 수정 후 (2026-10-30)

- AI 작성 내용(D6): `교육 플랫폼에서 과제를 제출하려면 '과제 제출' 메뉴를 이용하시기 바랍니다.`
- 판단 근거(E6): `공식 안내자료에 '과제 제출' 메뉴만 명시되어 있으므로, 해당 메뉴를 이용하도록 안내합니다.`
- 분류(C6): `공통 안내`.
- Make 4개 모듈 실행 후 동일 6행의 결과 갱신이 확인됨.
- **판정: 이 가상 문의 1건의 근거 준수 재시험 통과.**

## 4. 시험 결과 요약

| 항목 | 평가 |
|---|---|
| 분류 적절성 | 수정 전·후 모두 공통 안내로 일치 |
| 자료에 없는 단계·메뉴 생성 | 수정 전 실패 → 수정 후 제거 |
| 공식 근거 명시 | 수정 후 직접 근거로 개선 |
| 모듈 실행 및 기존 행 업데이트 | 통과 |
| 일반화 가능한 정확도·업무 시간 절감 | **미검증** |

## 5. 남은 확인 사항

1. 같은 뜻의 다른 표현, 다른 문의 유형에서도 근거 준수 여부 확인.
2. 공식 안내가 없을 때, 상충하거나 만료됐을 때 정보 확인 요청으로 분기되는지 확인.
3. 기본 자동화와 재처리 시나리오 간 중복·누락 가능성을 추가 검증.
4. 실제 운영 담당자의 업무 부담, 시간 절감 효과, 사용성은 아직 확인하지 못함.

## 6. 증거 파일 관리

본 문서는 실행 결과를 사용자가 제출한 캡처 및 답변 텍스트로 정리한 기록이다. 이 저장소에 캡처를 추가할 경우 계정 정보, 이메일, API 키, 내부 자료 등 민감한 정보를 제거한 뒤 별도 파일로 등록한다. 테스트 세트 전체의 성공률로 확대 해석하지 않는다.
