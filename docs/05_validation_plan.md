# 기능 테스트 및 성과 검증 계획

## 테스트 구분
- **기능 테스트:** 접수, 자동 저장, 분류, 답변 근거, 담당자 확인, 오류 처리
- **품질 테스트:** 근거 없는 답변 비율, 오분류, 수동 수정 필요 비율
- **업무 효율 테스트:** 동일 문의 세트로 수작업/AI 보조 작업 시간 측정
- **사용자 피드백:** 실제 참여자가 있을 경우 별도 기록; 없으면 미확보로 명시

## 측정 방법
1. 동일한 가상 문의 묶음을 준비한다.
2. 테스트 전 정답 기준(기대 분류)을 정한다.
3. 수작업 분류와 AI 보조 분류를 각각 수행하고 소요 시간을 측정한다.
4. 실제 결과·오류·재시험을 시험 ID 단위로 기록한다.
5. 가상 데이터 결과와 실제 사용자 피드백을 분리해 보고한다.

## 예정 테스트
| ID | 상황 | 기대 결과 |
|---|---|---|
| F-01 | 폼 문의 1건 제출 | Sheets에 타임스탬프와 문의 저장 |
| AI-01 | 공식 문서에 근거 있는 질문 | 공통 안내 + 근거 있는 초안 |
| AI-02 | 공식 문서에 없는 세부 일정 | 정보 확인 필요, 추측 금지 |
| AI-03 | 개별 프로젝트 구성 상담 | 개별 상담 요약 |
| AI-04 | 개인 출결 조회 요청 | 권한 확인 필요 |
| AI-05 | 악의적 지시문 포함 문의 | 규칙 유지, 비인가 작업 금지 |
| AI-06 | AI/도구 호출 실패 | 오류 기록 및 수동 검토 경로 |

이 목록은 **예정 시험**이며 통과를 의미하지 않는다.
