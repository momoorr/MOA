기준일: 2026-11-06
전략 버전: v0.3
최종 제출 준비 마감: 2026-11-11 18:00

## 1. 프로젝트 목표

1순위: 서비스기획 신입 취업을 위한 실제 작동하는 AI 에이전트 포트폴리오 완성

2순위: 취업 이후 독립적으로 운영할 수 있는 기업교육 서비스로 발전

현재는 상용 SaaS의 모든 기능보다 사용자 문제 정의, AI 에이전트의 실제 실행, 운영자 경험, 품질 검증을 우선한다.

## 2. 제품 포지셔닝

MOA는 기업교육 운영 문의의 공식 근거 확인과 담당자 검토에 집중하는 AI 에이전트 서비스다.

핵심 메시지:
"교육 운영의 질문을, 검증된 안내와 책임 있는 처리로 연결하다."

목표 사용자:
- 기업교육 운영 담당자
- 교육과정 담당자 및 강사
- 문의를 제출하는 교육생

주요 문제 가설:
- 반복 문의와 확인이 필요한 문의가 혼재한다.
- 교육과정별 안내의 적용 범위가 다를 수 있다.
- AI의 잘못된 안내를 막기 위해 근거와 승인 절차가 필요하다.
- 담당자 확인 결과를 향후 안내에 재사용할 수 있다.

운영자 인터뷰, 실제 처리 시간, 도입 의사는 아직 검증되지 않았다.

## 3. 경쟁 서비스: 채널톡

채널톡은 범용 고객 상담·CRM 플랫폼이다.

공식 제품 자료에서 확인한 주요 기능:
- AI 상담 에이전트 ALF
- 지식 기반 답변과 상담 규칙
- 업무 실행을 위한 태스크
- 상담원 연결과 상담 워크플로우
- 상담 기록을 활용한 지식 개선 제안
- 제안된 지식에 대한 사람의 승인·거절

따라서 단순 AI 응답, 상담 이관, 지식 승인만으로 MOA의 독점적인 기능을 주장하지 않는다.

## 4. MOA 차별화 전략

### 차별화 A. 교육과정별 공식 안내 적용 검증

교육과정, 기수, 승인 상태, 버전 및 적용 시점에 맞는 공식 안내를 사용하도록 설계한다.

현재 구현:
- 공식 안내ID
- 승인 상태
- 적용 과정
- 버전
- 승인 자료 재조회

추가 구현 필요:
- 문의의 소속 교육과정 식별
- 교육과정 일치 여부 검증
- 기수 및 적용 기간 판단
- 적용되지 않는 자료의 사용 차단

이 기능은 범용 상담 기능과 다른 도메인 특화 설계 방향이며, 경쟁 제품에서 구현 불가능한 기능이라는 주장은 아니다.

### 차별화 B. 미확인 문의의 지식화 흐름

목표 흐름:
문의 접수 → AI 근거 검색 → 정보 부족 판단 → 담당자 확인 요청 → 사람의 검토 → 공통 안내 승인 → 다음 문의에 재사용

현재 구현:
- 공식 안내 검색 도구 호출
- 담당자 확인 요청 등록 도구 호출
- 가상 공식 안내 승인 전후 재사용 시험

미완료:
- 운영자 화면에서 확인 결과를 공식 안내로 승인하는 통합 기능
- 승인 후 후속 문의에 적용되는 전체 E2E 검증

개인정보나 개별 상담 결과는 자동으로 공통 안내 자료로 전환하지 않는다.

### 차별화 C. 판단 근거 및 AI 실행 이력 확인

운영자가 단순한 AI 답변뿐 아니라 다음 정보를 확인하도록 설계한다.

- 원본 문의와 문의ID
- AI 분류
- 실행한 도구
- 공식 안내ID 및 버전
- 답변 초안
- 근거 부족 사유
- 담당자 검토·승인 상태

현재 Make 실행 로그와 일부 관리 시트 기록이 존재한다.
T13 운영자 콘솔과 통합된 이력 조회는 아직 미구현이다.

## 5. 취업 포트폴리오에서 보여줄 역량

문제 정의:
교육 운영에서 자동 안내가 가능한 업무와 사람이 판단해야 하는 업무를 구분했다.

기획 판단:
AI의 외부 발송 권한을 제한하고 사람의 최종 승인을 선택했다.

기술 이해:
LLM 호출과 실제 도구 실행형 AI 에이전트를 구분해 구현했다.

QA:
공식 자료에 없는 메뉴 생성 오류를 발견하고 개선 사례를 재시험했다.

데이터 관리:
문의ID, 처리 상태, 근거ID와 중복 처리 위험을 검토했다.

UX:
T13의 답변 수정, 검토 승인, 처리 완료, 승인 후 수정 시 재승인 정책을 재활용한다.

실제 사용자의 업무 효율 개선은 아직 측정되지 않았다.

## 9. 측정 및 검증 기준

- 신규 문의 처리 성공 건수
- 올바른 공식 안내ID 선택 여부
- 근거 없는 안내 생성 건수
- 담당자 확인 요청 성공 여부
- 중복 등록 건수
- 전체 흐름 완료 여부
- 운영자 검토·수정 필요 건수
- 처리 시간 측정 가능 여부

측정하지 않은 결과는 수치로 표현하지 않는다.
가상 시험 결과와 실제 교육 운영 성과를 구분한다.

## 10. 의사결정 기록

결정:
범용 상담 플랫폼과 기능 수로 경쟁하지 않는다.

이유:
채널톡과 같은 기존 제품은 이미 AI 상담, 지식 관리, 이관 및 업무 자동화 기능을 제공한다.

선택:
기업교육 운영의 적용 가능한 공식 안내, 미확인 문의 관리, 검토·승인 이력에 집중한다.

기대하는 포트폴리오 가치:
사용자와 업무 환경에 맞춰 기능의 범위, 권한, 우선순위, 예외 정책을 선택할 수 있음을 보여준다.

한계:
이 차별화가 실제 구매·도입 이유가 되는지는 아직 검증되지 않았다.
